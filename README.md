# 2v2matchmaking

[![License](https://img.shields.io/pypi/l/phasr.svg?color=green)](https://github.com/Partynumbers42/phasr/raw/main/LICENSE)

Android App for the automatic planing of fair 2 vs 2 matchups out of a pool of players with different skill levels. 

Uses Firestorm as a backend to store player data. With Optional Sportmember Integration.
